CHICKEN FARM - PYTHON AND TYPESCRIPT WITH JSON PERSISTENCE

Both programs save the chickens to "chickens.json" (in the folder from
which you run the program) and load it upon startup. They use the same
format, so the file works for both.

PYTHON:
  python pollo_granja.py

TYPESCRIPT (typescript folder):
  npm install
  npm start

Data is saved automatically whenever a chicken is added, deleted, or upon exiting.
To share data between Python and TypeScript, run both from the same
folder
