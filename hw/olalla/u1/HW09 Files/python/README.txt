CHICKEN FARM APP - PYTHON

Requirements: Python 3 (no extra packages needed).

Run:
  python ChickenFarmApp.py

The file chickens.json is created in this folder the first time data is saved.
It stores up to 10 chickens. IDs are generated randomly between 1000 and 9999
and checked against the IDs already loaded in memory.

Do not run the program from inside the model folder; run it from this folder.
